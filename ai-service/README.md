# CampusCoins AI Service (Phase 3 Blueprint)

This directory is designated for the **CampusCoins AI Microservice**, which will be implemented in **Phase 3**.

## Planned Technology Stack
- **Framework**: Python 3.11+, FastAPI, Uvicorn
- **AI / ML**: PyTorch / ONNX Runtime, Hugging Face Transformers, LangChain / LlamaIndex
- **Vision Models**: YOLO / CLIP for image verification of campus issues (potholes, water leaks, broken furniture)
- **NLP**: Semantic deduplication, priority scoring, automated routing to appropriate college departments

## Scope in Phase 1
> [!NOTE]
> Per Phase 1 specifications, this service is intentionally not implemented. The architecture and API contract blueprints are defined in `docs/architecture.md`.
